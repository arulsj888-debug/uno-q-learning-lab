# Review of the UNO Q lessons 18–23 and the Raspberry Pi 4 work (2026-11-06)

## What was checked
- **Every step of all 34 lessons** (23 UNO Q + 11 Pi 4) was opened in headless Chrome (`tools/dev/shot.js`, scenario `walk`): no script errors, no timeouts, no empty panels.
- `tools/check_code.mjs` (simulator line numbers) and `tools/check_lessons.mjs` (wiring, shorts, 3.3 V/5 V rules, text-vs-wire claims) pass; the checker was proven with planted mistakes.
- Phone-size layout (390 × 844) re-checked for Pi lessons 8 and 11.
- Positions of the Pi 4 chips and connectors re-checked by overlaying the model's boxes on the real photo (all fit); pin 1 = square pad, inner row, SD end, confirmed on the underside photo.
- Claims in the lesson texts were re-read against their sources (Raspberry Pi docs, datasheet, schematic, Flask docs, GPIO Zero, Adafruit guide, Arduino library source).

## Mistakes found and fixed
| Where | Problem | Fix |
|---|---|---|
| Pi Explore: USB 2.0 / 3.0 ports | I had given them reference labels J11 / J12 that are **not in the official schematic** | removed the labels (J1, J2, J3, J4, J6, J7, J8, J10, J13, J14 are confirmed by the schematic) |
| Pi Lesson 1 + USB-C card | "USB-C is only for power" — the schematic labels it "USB2 ONLY", and the docs only say it cannot connect a monitor | now: "the power input … cannot be used to connect a monitor" |
| Pi Lesson 7 | claimed `PWMLED` "works on any GPIO pin" — GPIO Zero's docs do not promise this for PWM | replaced by the datasheet statement (up to two PWM channels, e.g. GPIO12 and GPIO13) |
| Pi Lesson 10 | speculative sentence about browsers pre-loading links | removed |
| UNO Q Modulino Thermo, click card "Resistors and capacitors" | said the I²C lines have pull-ups — the datasheet only states pull-ups for ADDR and nRST | wording limited to what the datasheet says |

## Known limits (stated in the lessons or here)
- Nothing was run on real hardware: every sensor value, network request and LED state is simulated, and the lessons say so.
- Where the official docs print no output (terminal commands), the app explains instead of inventing output; example values are labelled "example".
- Pi 4 model: shape/positions from the official mechanical drawing, surface from CC BY-SA photos; heights of small chips and the PCB thickness are not in the official files (visual estimates, never quoted as facts). The Wi-Fi shield can is identified from the photo and board layout, not from an official text.
- Page size is ~19.5 MB (photo textures); first load on mobile data can be slow.
